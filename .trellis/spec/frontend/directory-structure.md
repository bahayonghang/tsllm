# Directory Structure

> How `web/` is organized.

---

## Layout

```text
web/
  package.json  pnpm-lock.yaml  biome.json  tsconfig.json  vite.config.ts  index.html
  openapi.json                  # exported by `uv run tsllm api openapi --out web/openapi.json`; committed
  src/
    main.tsx                    # providers: QueryClient, antd ConfigProvider (zhCN), Router
    router.tsx
    api/
      schema.d.ts               # generated by openapi-typescript; committed; never edit by hand
      client.ts                 # openapi-fetch client + ApiError
      hooks.ts                  # one TanStack Query hook per endpoint
      sse.ts                    # useRunEvents(runId)
    components/                 # shared components; charts/ and forms/ subfolders
    pages/                      # one file per route
    utils/                      # pure helpers (format.ts)
  tests/                        # *.test.ts(x), mirrors src/
  dist/                         # build output (gitignored)
```

---

## Routes

| Path            | Page file                     |
| --------------- | ----------------------------- |
| `/datasets`     | `pages/DatasetsPage.tsx`      |
| `/datasets/:id` | `pages/DatasetDetailPage.tsx` |
| `/runs`         | `pages/RunsPage.tsx`          |
| `/runs/new`     | `pages/RunNewPage.tsx`        |
| `/runs/:id`     | `pages/RunDetailPage.tsx`     |
| `/compare`      | `pages/ComparePage.tsx`       |
| `/system`       | `pages/SystemPage.tsx`        |

Page state that a user can share (selected split, channel, origin, run ids) goes into URL search parameters.

---

## Naming

- Components and pages: `PascalCase.tsx`, one exported component per file. Pages end with `Page`.
- Hooks: `useThing` in `camelCase`. API hooks are in `api/hooks.ts` only.
- Pure helpers: `camelCase.ts`.
- Tests: `<Name>.test.tsx` under `tests/` with the same relative path as the source file.

---

## Where New Code Goes

| New item                    | Location                                                                      |
| --------------------------- | ----------------------------------------------------------------------------- |
| New API endpoint use        | Regenerate `schema.d.ts`, add a hook in `api/hooks.ts`                        |
| New chart                   | `components/charts/<Name>Chart.tsx`                                           |
| New page                    | `pages/<Name>Page.tsx` + route in `router.tsx` + menu item in `AppLayout.tsx` |
| New backbone or task option | No web change. The schema form renders it.                                    |
