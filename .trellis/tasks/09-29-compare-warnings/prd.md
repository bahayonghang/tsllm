## 需求

### R1 中文展示及信息完整性

- R1.1 覆盖 RUN_NOT_SUCCEEDED、DATASET_MISMATCH、TASK_MISMATCH、CONTEXT_LENGTH_MISMATCH、HORIZON_MISMATCH、ORIGIN_SET_MISMATCH 六类既有警告及新增入库警告。
- R1.2 已知警告的主要说明使用中文。未成功运行可定位到运行，起点差异可定位到划分。ID、警告码和划分标识保持原值。
- R1.3 同码多条全部显示，保留相对顺序，不按码合并或丢弃。
- R1.4 旧响应缺少上下文时显示通用中文提示并保留原始详情；未知码显示中文通用提示及原始码和消息。禁止解析英文句子提取业务字段。

### R2 入库作业的明确警告

- R2.1 每个选中入库作业返回一条无实验指标警告。覆盖单入库、全入库、混合、反序及重复 ID。
- R2.2 保留 HTTP 200、去重后的全部列及原有指标行。入库缺失值维持 null，全入库的指标行为空列表。
- R2.3 未成功入库同时保留状态警告。其他既有差异仍按原规则产生警告。
- R2.4 对比只读取作业及指标，不修改状态、配置、指标或缓存。

### R3 响应兼容与类型一致性

- R3.1 保留 columns、rows、warnings 和既有 code/message。六类英文消息的内容与含义不变。
- R3.2 以可选上下文支持展示，旧响应省略字段仍可使用。未知码继续受支持，不收窄为封闭枚举。
- R3.3 同次生成 OpenAPI 与前端类型。比较模块负责业务判断，前端负责中文展示。

### R4 既有行为保持

- R4.1 可比成功实验仍无警告，指标数值、顺序和空值含义不变；网页继续把 null 显示为“—”。
- R4.2 保持重复 ID 去重、不存在 ID 的 404、非法参数的 422。
- R4.3 正常选择继续排除入库；手工混合链接保留 ID 并显示服务警告。
- R4.4 不改变指标算法、可比字段集合、起点判定、图表布局、状态机或数据规则。

### R5 验证与交付

- R5.1 使用合成作业及符合真实英文响应形状的夹具，覆盖接口到页面的提示链路。
- R5.2 后端四项和前端三项正式门槛通过，针对性测试不替代正式门槛。
- R5.3 可见浏览器检查 390 px、1280 px 的提示与两种入口；9000 服务使用独立临时合成目录。
- R5.4 区分静态、自动测试及可见浏览器证据，明确未执行项。
