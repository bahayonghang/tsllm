# 可见浏览器观察记录

日期：2026-09-30。主会话使用可见 Codex In-app Browser，通过 CUA 操作。视口为 1280×900 与 390×844 CSS px。截图仅在会话中查看，没有写入仓库。此记录不用于性能统计；性能原始数据由独立的 headless Edge 测量提供。

## B0

服务采用固定 source 后端、B0 生产产物和独立合成根目录，端口为 9000。以下各行均在两个视口查看了截图，并核对相应 DOM。

| 页面或状态 | 观察结果 |
| --- | --- |
| /runs | 5 个终态作业显示；2 个 ingest 复选框禁用。选择全部后按钮显示 3，点击进入包含 3 个实验 ID 的对比 URL。窄视口表格在容器内水平滚动。 |
| /compare 混合深链接 | 手动 URL 包含全部 5 个 ID。10 条警告覆盖 7 个代码；中文标题、运行名称与状态、英文诊断保留；5 列和空值破折号显示。实际 Canvas 柱状图显示 val/test 数据及图例。 |
| /runs/new | 表单显示真实 schema 字段。通过模板选择器加载 synthetic-preview，核对 Name、context_length=12、horizon=6，再打开提交前预览。两个视口可查看配置并返回修改；没有点击提交或另存为模板。 |

保留操作失败与修正：AntD 虚拟 option 的 role 定位点击超时，检查可见下拉后改为真实文本选项；模板选择后立即预览发生在异步模板应用前，核对字段完成后重试成功；数据集详情标题等待最初使用 synthetic-alpha，实际标题为“数据集 synthetic-alpha”，后续以真实 DOM 为准。以上未改产品。视口刚从 1280 切换到 390 时，首次整页截图包含图表调整前的宽度；随后核对完成后的 DOM 宽度并重新截图。

B0 检查后，浏览器导航到 about:blank；主会话通过所拥有的 exec session 43775 发送 Ctrl-C 结束服务。随后端口连接返回 10061，34 个合成文件哈希均未变化。端口已交给矩阵代理使用。
